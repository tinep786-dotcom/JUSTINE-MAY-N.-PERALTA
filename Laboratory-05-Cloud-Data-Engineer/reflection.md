# Mission Reflection

Working on this laboratory activity helped me understand how object storage works and why it is useful for cloud applications. Before doing the activity, I was more familiar with normal hard drives, but I learned that object storage is better for handling a large number of files because each file is stored as an object with its own information and unique ID. I also learned how Docker makes it easier to set up MinIO without manually installing everything on my computer. I only needed to use Docker commands, environment variables, and port forwarding to run and access the MinIO container. At first, some of the commands were confusing, especially when I encountered errors, but I slowly understood them as I continued. I also learned that a bucket is like a main container where objects are stored, while also having settings for permissions and access. The lab also introduced me to data redundancy, where copies of data can be stored on different disks or locations to help prevent data loss. Overall, this lab gave me more experience with Linux, Docker, and MinIO. I still have a lot to learn, but I am becoming more comfortable using the command line and troubleshooting simple problems. This activity helped me understand cloud storage better through actual hands-on practice.
